# ROADMAP — Toward the Framework End Goal

End goal (AGENTS.md): **a bulletproof, modular framework for rapidly iterating on mobile game prototypes in Godot 4.x.**

## Current state (solid ground)
- Boot pipeline + all singletons: Paths, EventBus, SaveSystem (versioned, migration hooks), SettingsManager, LocalizationManager (en/es), Analytics (pluggable backends), RemoteConfig (flags/values/experiments, FNV-1a A/B), AudioManager, AdManager (mock creatives), ScreenManager (cached screens + shell chrome), UIManager (dialog/tooltip/toast/tutorial overlays).
- 7 screens (home/profile/social/special/settings/game/results) with real persistence flows (profile picks, team join, offer claims, settings).
- `GameplayBase` contract + tap-target demo round; ThemeFactory theme system; animated offer widgets (sprite-art offers).
- Progression loop live: XP/levels (GDD §5), piggy bank deposits (GDD §6), FTUE v1 onboarding (GDD §8); GDD/TDD are the source of truth for design.
- Online services framework live (TDD §3.16): IdentityService + SocialManager/MockSocialBackend + SaveSystem sync hooks; **backend decided 2026-11-06 = self-hosted Nakama on one VPS (analytics = in-Nakama Go plugin)** (client contract TDD §3.17/§3.18, server spec BACKEND.md).
- GUT suite **265/265** green; **`tools/gate.sh` one-command gate is the Definition of Done** (import clean → boot with only the two documented audio lines → full suite); warnings treated as errors in `project.godot`; layout probe tools.
