## Done — FTUE "stuck on tutorial" fix (2026-11-05, user-reported input freeze)
Two stacked input-delivery bugs in TutorialHost; rationale + engine evidence in DECISIONS.md, gotchas in NOTES.md.
- [x] Bug 1: GUI events land on the topmost non-IGNORE control under the pointer (the full-rect STOP `_HighlightLayer`), so the host's own `_gui_input()` never fired — the layer now emits `signal input_received(event)` and the host handles it in `_on_overlay_input`.
